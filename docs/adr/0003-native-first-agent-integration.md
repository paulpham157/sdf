# Native first agent integration

SDF Core starts with one native coding-agent adapter and a fake adapter for deterministic tests. ACP v1 becomes an optional adapter only when a second coding-agent integration or client/editor portability justifies it; A2A remains deferred until a real remote specialist-agent or cross-trust-domain delegation use case exists. This keeps protocol maturity from becoming a dependency of the decision-and-evidence thesis.
